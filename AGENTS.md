# Instructions pour les agents de développement

Les règles du projet Energy Plus sont dans **[CLAUDE.md](CLAUDE.md)** (règles générales) et **[.claude/rules/](.claude/rules/)** (règles par domaine : sécurité, base de données, frontend, backend, SEO, tests). Lisez-les avant toute modification ; elles s'appliquent à tous les agents, quel que soit l'outil.

Rappels non négociables :
- Phase actuelle : conception. Aucun développement sans validation écrite du propriétaire.
- Aucun commit, push, pull request ni publication.
- Aucune modification de service externe (Neon, KPay, Hostinger, DNS) sans autorisation explicite.
- Aucun fichier original supprimé ou écrasé.

Ce fichier ne duplique pas les règles, pour éviter les contradictions : en cas de doute, CLAUDE.md fait foi.
